# Микрокод видеодекодера (meson-vdec)

⚠️ **Сами `.bin` в git не коммитятся.** Здесь только контрольные суммы
(`SHA256SUMS`) и способ получить файлы. Без них сборка AOSP остановится на
`PRODUCT_COPY_FILES`.

Происхождение и лицензия — [`kernel/firmware/README.md`](../../../kernel/firmware/README.md).

## Как заполнить

```bash
build/fetch-firmware.sh     # из корня репозитория; сверяет SHA-256 каждого файла
```

## Состав

| Файл | Размер | Зачем |
|---|---:|---|
| `gxl_hevc.bin` | 16 КиБ | HEVC/H.265 |
| `gxl_hevc_mmu.bin` | 16 КиБ | **HEVC через MMU — путь для крупных кадров, то есть 4K** |
| `gxl_vp9.bin` | 16 КиБ | VP9 |
| `gxl_h264.bin` | 36 КиБ | H.264, вариант GXL |
| `gxm_h264.bin` | 36 КиБ | H.264, вариант GXM — наш SoC |
| `gxl_mpeg12.bin` | 16 КиБ | MPEG-1/2 |

`gxl_hevc_mmu.bin` легко пропустить — имя похоже на «дополнительный», — но
именно он отвечает за декодирование больших кадров. Без него HEVC работал бы
на 1080p и молча отказывал на 4K.
