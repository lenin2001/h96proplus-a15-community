# rescue — среда восстановления на SD-карте

Минимальный Linux (наше ядро + busybox), который загружается **с SD-карты**,
чтобы внутренняя eMMC была свободна и [установщик](../installer/README.md)
мог её прочитать и записать. Сам rescue в eMMC ничего не пишет и ничего с
карты или из сети не исполняет.

> ⚠️ **Пока rescue работает, любой, кто достаёт до приставки по сети, получает
> root-консоль без пароля** (busybox telnetd, порт 23). Пользуйтесь им только по
> прямому кабелю ПК — приставка или в изолированной сети. Закончили — разоружите
> карту и выключите приставку.

**Статус:** публичная версия упрощена относительно рабочей у сопровождающего
(убраны самозапись образов на карту без проверки хэшей, HTTP-сервер со всей
файловой системой и запасная консоль на порту 24; сеть стала настраиваемой).
**На железе эта версия ещё не проверялась.** Механизм загрузки с карты
(`aml_autoscript` + `RESCUE.TAG`) — тот же, что использовался на приставке.

## Сборка

```bash
rescue/build-busybox.sh /tmp/bb                     # busybox 1.36.1, статически, aarch64
# ядро: build/prepare-kernel.sh + build/build-kernel.sh → Image и meson-gxm-h96proplus.dtb
rescue/mkrescue.sh --kernel OUT/arch/arm64/boot/Image --busybox /tmp/bb/busybox --out /tmp/rescue
rescue/sd/build-autoscript.sh --rescue /tmp/rescue/rescue.img \
    --dtb OUT/arch/arm64/boot/dts/amlogic/meson-gxm-h96proplus.dtb --out /tmp/card
```

`/tmp/card` содержит `aml_autoscript`, `RESCUE.TAG`, `rescue.img`, `dtb.img` и
`SHA256SUMS`. Скопируйте их на FAT-раздел карты (первый раздел) — карта
**взведена**.

## Сеть

Без настройки rescue берёт адрес по DHCP. Статический адрес — файл
`h96-rescue.conf` в корне FAT-раздела:

```text
RESCUE_IP=192.0.2.202
RESCUE_NETMASK=255.255.255.0
RESCUE_GW=192.0.2.1
```

Читаются только эти три ключа и только в виде IPv4-адресов. Адрес, который
rescue получил, записывается в `RESCUE.LOG` на карте и выводится в консоль.

## Взвести и разоружить

| Состояние | Файлы на FAT-разделе | Что сделает загрузчик |
|---|---|---|
| взведена | `aml_autoscript`, `RESCUE.TAG`, `rescue.img`, `dtb.img` | загрузит rescue |
| разоружена | `aml_autoscript.off` (переименован), без `RESCUE.TAG` | не тронет карту, загрузит eMMC |

- **Первая установка со стоковой прошивки:** загрузчик Amlogic выполняет
  `aml_autoscript` с карты на пути обновления/восстановления; обычно в него
  попадают, удерживая кнопку в гнезде AV при подаче питания. Проверьте способ
  на своей приставке — у разных партий он может отличаться.
- **Из установленной системы проекта:** `rescue/tools/rescue-arm.sh`
  (ADB с root) переименует `aml_autoscript.off` → `aml_autoscript`, создаст
  `RESCUE.TAG` и перезагрузит приставку в rescue.
- **Разоружить из rescue:** `installer/h96install.py rescue-disarm --target IP [--reboot]`.

Не оставляйте приставку с взведённой картой: каждая перезагрузка будет
приводить в rescue с открытой консолью.
