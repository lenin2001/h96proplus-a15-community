# Device Tree

`meson-gxm-h96proplus.dts` — Device Tree платы H96 Pro Plus (CZ-S32-V3), ровно
тот файл, из которого собрано ядро #112 (SHA-256 `e84b56b7aa5de78a…`, сверено
10.10.2026 с деревом сборки). DTB из него побайтно равен DTB, установленному на
приставку сопровождающего (`26f81f595d10487f92674e681f9809a763a7aed3d66ba4ff09f6d30205a3ffc9`).

Комментарии в файле местами старые (пометки `TODO(M1)`, «3 GiB по наклейке»):
файл оставлен как есть, чтобы совпадение с собранным деревом было проверяемым.
Где комментарий и факты расходятся, верны факты ниже.

## Основа: Q200, а не Q201

Multi-DTB стоковой прошивки называет варианты `gxm/q201/{1,2,3}g`, но
mainline-овский `meson-gxm-q201.dts` описывает плату с внутренним 100-мегабитным
PHY. На этой плате распаян внешний RTL8211F (`phy-mode = "rgmii"`), как у
референса Q200, поэтому DTS подключает `meson-gxm.dtsi` и
`meson-gx-p23x-q20x.dtsi` и уточняет их. С основой Q201 Ethernet работал бы
на 100 Мбит.

## Что добавлено поверх Q200

- `meson_gx_pm: pm` — узел драйвера питания `kernel/meson_gx_pm.c` (сон и
  пробуждение пультом);
- `memory@0` объявлен на 3 ГиБ, но U-Boot сам передаёт ядру реальные **2 ГиБ** —
  вариант `3g` в стоковом multi-DTB лежал про запас;
- `reserved-memory`, кнопки (`adc-keys`, `gpio-keys-polled` с `KEY_POWER`), LED;
- `&ethmac`/`&external_mdio`: RTL8211F, сброс и прерывание PHY;
- `&sd_emmc_a`: Wi-Fi QCA9377 по SDIO; `&uart_A`: Bluetooth;
- `&ir`: совместимость `amlogic,meson-gxbb-ir` — приёмник отдаёт сырые импульсы,
  NEC декодирует rc-core, режим мыши ведёт демон `h96mouse` в пространстве
  пользователя (регистр фильтра после сна восстанавливает ядро 0046).

## Где лежит DTB на приставке

Не в boot.img: загрузчик берёт DTB из двух 256-КиБ записей раздела `reserved`
(смещения +4 МиБ и +4 МиБ+256 КиБ) со служебным хвостом. Рядом в `reserved`
хранятся ключи и калибровка, поэтому писать туда можно только полезную нагрузку
записей — это делает [установщик](../installer/README.md), сверяя остаток записи
с бэкапом.

## Сборка

DTS копируется в дерево ядра шагом ряда `kernel/patches/series.json`;
`build/build-kernel.sh` собирает DTB вместе с ядром. Отдельно:

```bash
make ARCH=arm64 amlogic/meson-gxm-h96proplus.dtb   # цель относительно arch/arm64/boot/dts/
```

Сверить DTB конкретной приставки можно только чтением: снять запись из
`reserved` (+4 МиБ), отрезать хвост и сравнить `dtc -I dtb -O dts` с собранным.
